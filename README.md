# Tableau Data Analytics Portfolio

Portfolio de tableaux de bord interactifs réalisés avec **Tableau**, mettant en pratique la visualisation de données, la création de champs calculés, les actions/filtres interactifs et le design de dashboards.

## Projets

| Projet | Description |
|---|---|
| [Global Development Dashboard](./global-development-dashboard) | Analyse comparative du développement mondial (CO2, PIB, espérance de vie, IDH) pour 175 pays entre 1998 et 2018 |

## Compétences démontrées

- Modélisation et champs calculés dans Tableau
- Visualisations dynamiques (KPI, jauges, classements, nuages de points, cartes)
- Interactivité avancée (filtres croisés par actions, infobulles personnalisées)
- Design et mise en page de tableaux de bord (alignement, hiérarchie visuelle, navigation)
